    Course & Outcomes Setup

    No course configured yet

    Course information

    Matches the header fields on the original Class List sheet.

    Assessment thresholds

    Defaults match the workbook — mastery: a student "passes" an item by scoring ≥ 70% of its max; achievement levels change at 60 / 70 / 85%.

    Course Learning Outcomes (CLOs)

    One row per CLO — this is the finest-grained outcome, assessed directly by exam/assignment questions.

    Student / Program Outcomes (PLOs)

    The 7 broad ABET outcomes (or your program's equivalents). Each CLO below will be mapped to one or more of these.

    Outcome Indicators (optional)

    Finer-grained indicators (e.g. "2a", "2b") that, like CLOs, are assessed directly by questions — for programs that track sub-indicators separately (mirrors the workbook's SO_Results sheet).

    Class roster

    Click a cell to type, or select the first ID cell and paste a block copied from Excel (Nb / ID / Name columns).

    Assessment instruments

    Groups (e.g. "Exam 1", "Assignments") each contain items (e.g. "Pb1") with a maximum score. These items are what CLOs/indicators get mapped to.

    Grade entry

    Row 1 under each item header is the maximum possible score. Paste a block from Excel starting at any score cell to fill quickly.
    Check every item whose questions assess a given CLO. A CLO is "met" using the average pass rate across all checked items.

    Course Learning Outcomes (CLO)

    Achievement level & percentage per CLO, computed from mapped items.

    Outcome Indicators

    Achievement level & percentage per indicator, computed from mapped items.

    Student / Program Outcomes (PLO)

    Averaged from the % achievement of every related CLO / indicator.

    Charts

    Bars are colored by achievement level. Grade distribution uses the computed final marks.

    Generate report

    Filter by achievement level and/or a minimum % — the sections below update, and the printable report always keeps CLOs, indicators and PLOs together.
